Report card

Your Advanced Higher subjects, graded by topic. Move a slider after a test or past paper and the rating updates — clear bronze, silver, and gold once a subject is genuinely strong across the board.

Loaded from data.json

Commits your current progress straight to data.json in the repo, so the other computer just needs to git pull or reload the live site. Use a fine-grained personal access token scoped only to this one repo's contents — it's stored in this browser's local storage, nowhere else.

Changes save to this browser automatically. To sync between two computers, click Export data.json, replace data/data.json in the repo with the downloaded file, then commit and push. On the other computer, pull the latest changes and click Import data.json (or just clear local changes to reload from the file).
